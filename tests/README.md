# Тесты

Этот каталог содержит автотесты для проверки работоспособности системы.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

Запустить все тесты:
```bash
pytest
```

Запустить конкретный файл тестов:
```bash
pytest tests/test_modbus_service.py
```

Запустить с подробным выводом:
```bash
pytest -v
```

Запустить с выводом логов:
```bash
pytest -s
```

## Структура тестов

- `test_modbus_service.py` - тесты для работы с Modbus устройством
- `test_camera_service.py` - тесты для работы с камерами
- `test_modbus_poller.py` - тесты для фонового поллера Modbus
- `test_api.py` - тесты для API эндпоинтов

## Примечания

- Большинство тестов используют моки (mock) для изоляции от внешних устройств
- Для тестов API может потребоваться настройка авторизации
- Некоторые тесты могут быть пропущены (skip), если требуемые зависимости недоступны
