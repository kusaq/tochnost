# RZhD FastAPI backend

Сервис объединяет сбор фотографий с камер Hikvision и считывание данных с Modbus-преобразователя. Построен на FastAPI, есть авторизация по токену.

## Подготовка

1. Установите Python 3.10+.
2. Скопируйте `env.sample` → `.env` и заполните свои значения (секрет, логин/пароль, IP камер и Modbus).
3. Поднимите PostgreSQL (минимум 14), создайте базу и укажите `DATABASE_URL` в `.env`.
4. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск API

```
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Документация будет доступна по адресу `http://localhost:8000/docs`. Сначала получите токен через `/auth/token`, затем подставьте `Bearer <token>` для всех защищённых запросов.

## Основные эндпоинты

- `POST /auth/token` — получить JWT по логину/паролю из `.env`.
- `GET /health` — проверка работоспособности (без авторизации).
- `POST /api/v1/capture` — запуск сбора фото. Можно использовать настройки по умолчанию либо задать свои RTSP-ссылки и параметры съёмки.
- `POST /api/v1/cameras/test` — проверка доступности переданных RTSP/HTTP камер.
- `POST /api/v1/modbus/readings` — ручное чтение значений (по умолчанию: 4 гайковёрта + сопротивление). В теле запроса можно переопределить список регистров.
- `GET /api/v1/modbus/poll/status` — статус автоматического опроса Modbus (работает ли, сколько раз опросил, последняя ошибка).
- `POST /api/v1/modbus/poll/start` — запустить автоматический опрос Modbus.
- `POST /api/v1/modbus/poll/stop` — остановить автоматический опрос Modbus.
- Результаты `capture` и `modbus` автоматически сохраняются в таблицы PostgreSQL (`capture_sessions`, `modbus_readings`).

## Автоматический опрос Modbus

Приложение автоматически опрашивает Modbus преобразователь в фоновом режиме (если включено в настройках). 

**Настройки в `.env`:**
- `MODBUS_POLL_INTERVAL_SEC=1.0` — интервал опроса в секундах (по умолчанию 1 секунда)
- `MODBUS_POLL_ENABLED=true` — включить/выключить автоматический опрос при старте

**Как это работает:**
1. При запуске приложения (`uvicorn app.main:app`) автоматически стартует фоновый опрос Modbus
2. Каждые N секунд (задаётся в `MODBUS_POLL_INTERVAL_SEC`) приложение читает все регистры по умолчанию (4 гайковёрта + сопротивление)
3. Все прочитанные значения автоматически сохраняются в таблицу `modbus_readings` в БД
4. Можно управлять опросом через API: проверить статус, остановить/запустить вручную
5. При остановке приложения опрос корректно завершается

**Отличия:**
- Ручной запрос `/api/v1/modbus/readings` — одноразовое чтение по запросу, можно указать свои переменные
- Автоматический опрос — работает постоянно в фоне, использует переменные по умолчанию, все данные сохраняются в БД

## CLI-скрипты

Для отладки вне API сохранились исходные скрипты:

- `python collect_data.py` — ручной сбор изображений (использует настройки из `hikvision.env.sample` или `.env`).
- `python modbus_read_test.py` — циклическое чтение регистров Modbus.
