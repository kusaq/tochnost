# ADR-0001. На посту 1 — парковка, не закрытие

**Статус:** принято · **Инвариант:** INV-1

## Контекст
РШР проходит пост 1 (геометрия), затем пост 2 (закрутка). Раньше при уходе с поста 1 вызывался `close_active_rail` → РШР финализировалась **до** закрутки. Число шпал считается как `ceil(гайки/4)`, а гайки на посту 1 ещё не закручены → в таблице появлялось **0** (или ~20 при частичной закрутке) шпал вместо ~50.

## Решение
Уход с поста 1 = `park_active_for_post2()`: сессия переносится в `waiting_at_post2` **без** финализации. `finalize_rail()` вызывается **только** при уходе с поста 2. Число шпал считается там, где гайки уже посчитаны.

## Последствия
- Между постами РШР живёт как `IN_PROGRESS` (легитимно, см. ADR-0006).
- Число шпал корректно (~50) и появляется только после реальной закрутки.
- Нельзя финализировать РШР на посту 1 ни при каких условиях.

## Отвергнутые альтернативы
- *Считать шпалы по геометрии на посту 1* — данные о шпалах приходят с закрутки (Modbus), не с геометрии.
- *Дописывать шпалы задним числом* — нарушает «не правим органику».
