# ADR — записи архитектурных решений

> Каждый инвариант из [SPEC.md §6](../../SPEC.md) — это шрам от реального инцидента на заводе. ADR хранит **почему** решение принято, чтобы агент не «упростил» его обратно в баг.
>
> Формат: Контекст → Решение → Последствия → Отвергнутые альтернативы → Где в коде.
