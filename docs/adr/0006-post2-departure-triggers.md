# ADR-0006. Триггеры ухода с поста 2 и парковка между сменами

**Статус:** принято · **Инварианты:** INV-1, INV-7

## Контекст
На посту 2 (и посту 1) физически не может быть двух РШР одновременно: заезд новой = предыдущая обязана уйти. Но данные разреженные — нулевые пакеты **не** приходят, когда РШР стоит (сенсоры пишут только при изменении `mmAlongRail`, Modbus тоже может молчать). Значит нельзя закрывать РШР по «тишине». При этом надо отличать **реальный уход** от **парковки между сменами** (недокрученная РШР стоит ПОД лазером поста 2 в конце смены).

## Решение
`rail_at_post2` финализируется по **любому** из триггеров (в порядке приоритета):
1. **Чистый OFF лазера** после реального прохода (`rail_at_post2_max_mm` дотянул до длины) → закрытие через **settle** `POST2_DEPART_SETTLE_SEC` (15 с) — досчитать «хвост» закрутки (моменты приходят ещё ~5–10 с после гашения лазера). Основной путь.
2. **Заезд следующей решётки** (`_confirm_post2_segment`) → прошлый `rail_at_post2` финализируется **принудительно**, даже если FIFO пуст.
3. **Grace-фолбэк** `POST2_DEPART_GRACE_SEC` (120 с) — если чистого OFF не было (рельс встал за лазером, пакеты прекратились; сирота без длины). Страхует последний рельс смены.

**Парковка между сменами безопасна:** припаркованный недокрученный рельс лежит ПОД лазером (`post2_laser_was_on == True`) → не трогаем. Финализация срабатывает только по реальному уходу (лазер был и погас). Допустима **ровно одна** такая `IN_PROGRESS`; `rehydrate_in_progress_rails()` восстанавливает её при рестарте.

Пост 1 симметрично: `active` паркуется по своему OFF (рельс прошёл `traversed_mm ≥ порога` и mm сбросился к ~0), не дожидаясь распознавания на посту 2.

## Последствия
- Нет зависших РШР и нет потерянных циклов закрутки при разреженных данных.
- Нельзя путать «лазер погас, рельс уехал» (финализировать) и «рельс стоит под лазером» (парковка).

## Отвергнутые альтернативы
- *Закрывать по таймауту тишины* — режет парковку между сменами и последний рельс.
- *Закрывать только по OFF лазера* — теряет рельсы, вставшие за лазером.
