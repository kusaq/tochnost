# ADR-0003. Число шпал = `ceil(гайки/4)`; «—» для IN_PROGRESS

**Статус:** принято · **Инвариант:** INV-3

## Контекст
Одна шпала = 4 гайки. Число шпал на РШР выводится из числа гаек. Пока РШР `IN_PROGRESS`, гайки ещё докручиваются — показывать промежуточное число (например 0 или 12) вводит оператора в заблуждение (выглядит как брак).

⚠️ Терминология: то, что считает система — **число шпал** (поле `sleepers`). «Эпюра» строго — расстояние между шпалами; UI-колонка названа «Эпюра» по историческим причинам. См. [GLOSSARY](../GLOSSARY.md).

## Решение
- `sleepers = ceil(число_гаек / 4)`, вычисляется **только** при финализации (уход с поста 2).
- Для `IN_PROGRESS` UI показывает **«—»**, не 0 (`rzd/src/shared/lib/rail-utils.ts`).
- Допустима ровно одна `IN_PROGRESS` (парковка между сменами, см. ADR-0006).

## Последствия
- Промежуточные значения не путают оператора.
- Число шпал финально и стабильно после закрытия.

## Отвергнутые альтернативы
- *Показывать live-счётчик шпал как финальный* — сбивает с толку, выглядит как аномалия.

## Где в коде
`tochnost/.../sensor/service.py: finalize_rail`; `rzd/src/shared/lib/rail-utils.ts`. FAQ-1 онбординга.
