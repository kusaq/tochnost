# ADR-0009. На проде `VITE_API_BASE_URL` пустой

**Статус:** принято

## Контекст
Фронтенд (`rzd`) собирается в Docker и раздаётся через nginx на порту 3003. В браузере оператора запросы к API должны идти на тот же хост через nginx-прокси (`/api` → backend). Ошибочно ставили `VITE_API_BASE_URL=host.docker.internal` — это адрес для **сборки** внутри Docker, недоступный из браузера оператора → API-запросы падали.

## Решение
На проде `VITE_API_BASE_URL` — **пустой** (относительные пути). Браузер ходит на `:3003/api/...`, nginx проксирует на backend. В dev — Vite proxy `/api` → `localhost:8000`.

## Последствия
- Один хост для UI и API у оператора, без CORS и без утечки внутренних адресов.
- `host.docker.internal` использовать **только** при необходимости на этапе Docker-сборки, никогда как runtime-адрес браузера.

## Где в коде
`rzd/vite.config.ts` (dev proxy), `rzd/nginx.conf`, `.env` фронта. FAQ-14 онбординга.
