# Настройка переменных окружения

## Быстрый старт

1. Скопируйте файл `env.sample` в `.env`:
   ```bash
   cp env.sample .env
   ```

2. Откройте `.env` и заполните все необходимые значения:
   - IP адреса камер Hikvision
   - Пароли и учетные данные
   - Настройки Modbus устройства
   - Строка подключения к базе данных

3. **ВАЖНО**: Измените `API_SECRET_KEY` на случайную строку для безопасности!

## Структура переменных

### Обязательные переменные

- `API_SECRET_KEY` - секретный ключ для JWT токенов (ОБЯЗАТЕЛЬНО измените!)
- `API_USERNAME` - имя пользователя для входа в API
- `API_PASSWORD` или `API_PASSWORD_HASH` - пароль (в открытом виде или хеш)
- `DATABASE_URL` - строка подключения к PostgreSQL
- `MODBUS_IP` - IP адрес Modbus устройства
- `HIKVISION_TOP_IP` - IP адрес верхней камеры
- `HIKVISION_FRONT_IP` - IP адрес фронтальной камеры

### Опциональные переменные

Все остальные переменные имеют значения по умолчанию и могут быть не указаны.

## Безопасность

- **НЕ коммитьте** файл `.env` в публичные репозитории
- Используйте `API_PASSWORD_HASH` вместо `API_PASSWORD` в продакшене
- Регулярно меняйте `API_SECRET_KEY`

## Генерация хеша пароля

Для генерации bcrypt хеша пароля:

```bash
python -c "from passlib.context import CryptContext; ctx = CryptContext(schemes=['bcrypt']); print(ctx.hash('your_password'))"
```

Затем укажите полученный хеш в `API_PASSWORD_HASH` в `.env` файле.
